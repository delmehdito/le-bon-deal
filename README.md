# Le Bon Deal

Bienvenue sur Le Bon Deal !

Le Bon Deal est un projet d'application mobile qui facilite la recherche de bonnes affaires et de services.

## Nos catégories

- 🛠️ Réparation et construction
- 🛍️ Achat et bonnes affaires

## Objectifs

- Trouver facilement un service ou un article.
- Proposer une interface simple et adaptée aux téléphones.
- Développer progressivement une plateforme accessible à tous.

## État du projet

Le projet est en cours de création. Les fonctionnalités seront ajoutées progressivement.
